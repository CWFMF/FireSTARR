133 /*
134 * Field Natural Range Used Range Bits Bit Range
135 * Y 0 - 4095 0 - 4095 12 0 - 4095
136 * X 0 - 4095 0 - 4095 12 0 - 4095
137 * PADDING 10
138 * Fuel 0 - 140 0 - 140 8 0 - 255
139 * Aspect 0 - 359 0 - 359 9 0 - 511
140 * Slope 0 - infinity 0 - 511 9 0 - 511
141 * Extra 8
142 *
143 * X and Y are restricted to 4096 since that's what gets clipped out of
144 * the GIS outputs.
145 *
146 * Fuel is tied to how many variations of percent conifer/dead fir we want to use, and
147 * if we want to allow M1/M2/M3/M4 on their own, or just use the ones that are
148 * automatically tied to the green-up.
149 *
150 * Aspect is calculated to be in degrees, so 0 - 359.
151 *
152 * Slope is truncated to 0 - 70 for slope effect calculations speed for slopes,
153 * but keep higher range because there's an issue with this when it tries to calculate the
